# Task Manager App

A full-stack task management application built using the MERN stack (MongoDB, Express, React, Node.js).

## Features
- Create, update, complete, and delete tasks.
- Filter tasks by status (All, Pending, Completed).
- High/Medium/Low priority tagging.
- RESTful API backend with Express and Mongoose.

## Setup Instructions

### Backend
1. `cd backend`
2. `npm install`
3. `npm start` (Runs on http://localhost:5000)

### Frontend
1. `cd frontend`
2. `npm install`
3. `npm run dev` (Runs on http://localhost:5173)
